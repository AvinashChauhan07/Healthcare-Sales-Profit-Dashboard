# Healthcare Sales & Profit Dashboard (Tableau)

## 📌 Overview
This project focuses on analyzing healthcare sales and profit data using Tableau.  
An interactive dashboard was developed to visualize trends, KPIs, and business insights.

## 🎯 Objectives
- Analyze sales and profit trends
- Build an interactive dashboard
- Enable filtering by region, department, and procedure type
- Provide actionable insights

## 🛠 Tools & Technologies
- Tableau Public
- Microsoft Excel
- Data Visualization

## 📊 Dashboard Features
- KPI Metrics (Total Sales, Total Profit)
- Monthly Sales Trend (Area Chart)
- Monthly Profit Trend (Area Chart)
- Interactive Filters:
  - Customer Segment
  - Region
  - Procedure Type
  - Department
